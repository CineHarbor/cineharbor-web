# Evidence — douban-imdb-rt P1（IMDb 官方 datasets 零 key 接入）

日期：2026-08-31（Join 目标 = 方案 `docs/plans/douban-imdb-rt-integration-plan.md` P1）。

## 结论

P1 落地完成：IMDb 评分走官方公开 datasets 的「标题 + 年份」反查路径，**不需要任何 API key**。反向查询不是 `douban_id → imdb_id`（豆瓣 subject JSON 无该字段），而是用 `title.akas` 里的中文别名建立「标准化标题键 → imdb_id」索引，运行时用同一归一键做正向命中，`douban_id` 仅作为可选锚点。

## 落地内容

- `scripts/sync-imdb.js`（`pnpm sync:imdb`）：下载 `title.ratings/basics/akas.tsv.gz`，过滤（仅 movie/tvMovie/tvSeries/tvMiniSeries + 非成人 + 有评分），浓缩为 `data/imdb-index.json`（`IMDB_INDEX_PATH` 可覆盖），字段 `{version, generated_at, ratings: {imdb_id→{value,votes}}, titles: {key→[{id,year,type,votes}]}}`。
- `src/lib/ratings/imdb/title-key.js`：**单一标题归一键**（NFKC + 小写 + 去括号副标题 + 去季部后缀 + 折叠空白），运行时 `title-normalize.ts` 与同步脚本都从这里取，防 key 漂移。
- `src/lib/ratings/providers/imdb.ts`：懒加载索引（ENOENT 静默降级，其余错误 `console.warn` 一次）；`resolve` 先试显式 `imdb_id`，再按 `toTitleMatchKey(title)` 查候选，年份精确匹配优先、剧集允许 ±1、类型加权，取评分。
- `src/app/play/page.tsx`：详情页关键信息行展示 `IMDb x.x/10 · x万票`（品牌黄 `#f5c518`，链到 IMDb 页面），失败静默降级不影响播放主链路。

## 关键决策

- 索引 key 由同步脚本预生成、运行时正向命中，故两者必须用**同一归一键**；用共享 `title-key.js`（无需把 TS 编译进 Node 脚本，也无需依赖 ts-node/tsx）。
- 索引放 `data/` 并 `gitignore`（生成物不入库），运行时 `process.cwd()/data/imdb-index.json`。
- 保持 provider 门控契约：未索引 / 未配置时返回 `undefined`，不影响豆瓣与其它源。

## 验证

- `pnpm typecheck`、`pnpm test`（109 套件 / 522 测试全绿）、`pnpm build`（exit 0，Lint 过）。
- `pnpm sync:imdb` 全量跑通（`--max-old-space-size=4096`；初版因嵌套 Map 在 2GB 堆 OOM，改纯对象 + 仅保留电影/剧集评分后 60.5s 完成）：631,158 标题键 / 541,334 评分，`data/imdb-index.json` 71 MB。
- 抽样验证命中正确：`流浪地球2(2023)→tt13539646`、`流浪地球(2019)→tt7605074`、`进击的巨人(2013)→tt2560140`、`The Dark Knight(2008)→tt0468569`（中文别名与原件名两条路径均命中）。
- 新增 `providers.test.ts`（显式 id / 标题+年份 / 年份强不一致排除 / 空索引）与 `imdb/sync-imdb.test.ts`（过滤逻辑）共 5 例。
